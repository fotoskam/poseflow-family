# PoseFlow Family

Egyszerű, keretrendszer nélküli, 40 kártyás statikus fotós instrukciógyűjtemény. GitHub Pages-kompatibilis.

## Használat

Nyisd meg az `index.html` fájlt, vagy töltsd fel a mappa teljes tartalmát egy GitHub repository gyökerébe, majd kapcsold be a GitHub Pages szolgáltatást a `main` ág gyökerére.

Mobilon a kártyák vízszintesen, egyesével lapozhatók. A képre koppintva teljes képernyős galéria nyílik; húzással, nyilakkal vagy billentyűzettel léptethető. Az évszak- és szereplőszűrő egymással kombinálható, a galéria mindig csak a szűrt kártyák között léptet.

## Fájlok

- `index.html` – oldalstruktúra
- `styles.css` – arculat és reszponzív nézet
- `script.js` – a 40 instrukció, a két szűrő és a galériavezérlés
- `assets/` – 40 különálló, jelenethez illő, mobilra optimalizált kép
