# PoseFlow Family

Egyszerű, keretrendszer nélküli, statikus fotós instrukciógyűjtemény. GitHub Pages-kompatibilis.

## Használat

Nyisd meg az `index.html` fájlt, vagy töltsd fel a mappa teljes tartalmát egy GitHub repository gyökerébe, majd kapcsold be a GitHub Pages szolgáltatást a `main` ág gyökerére.

Mobilon a kártyák vízszintesen, egyesével lapozhatók. A képre koppintva teljes képernyős galéria nyílik; húzással, nyilakkal vagy billentyűzettel léptethető.

## Fájlok

- `index.html` – oldalstruktúra
- `styles.css` – arculat és reszponzív nézet
- `script.js` – a 20 instrukció és galériavezérlés
- `assets/` – a 20, jelenethez illő, mobilra optimalizált WebP kép
