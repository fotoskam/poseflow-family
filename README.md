# PoseFlow Family

Egyszerű, keretrendszer nélküli, 79 kártyás statikus fotós instrukciógyűjtemény: 40 családi, 20 páros és 19 karácsonyi iskolai jelenettel. GitHub Pages-kompatibilis.

## Használat

Nyisd meg az `index.html` fájlt, vagy töltsd fel a mappa teljes tartalmát egy GitHub repository gyökerébe, majd kapcsold be a GitHub Pages szolgáltatást a `main` ág gyökerére.

Mobilon a kártyák vízszintesen, egyesével lapozhatók. A képre koppintva teljes képernyős galéria nyílik; húzással, nyilakkal vagy billentyűzettel léptethető. A Család/Párok/Karácsonyi fotózás választó külön adatkészleteket mutat. Az évszak- és családi szereplőszűrő egymással kombinálható, a galéria mindig csak az aktív kategória szűrt kártyái között léptet.

## Fájlok

- `index.html` – oldalstruktúra
- `styles.css` – arculat és reszponzív nézet
- `script.js` – a 79 instrukció, a kategóriaválasztó, a szűrők és a galériavezérlés
- `assets/` – 79 különálló, jelenethez illő kép
